## CSS Grid Usage
- CSS Grid is used to arrange the KPI summary cards and the
- two charts in the dashboard layout.

## Flexbox Usage
- Flexbox is used to align the navigation bar items and the
- content inside the KPI cards.

## Responsive Design
- Media queries are used to adjust the layout for desktop
- tablet and mobile screen sizes.
